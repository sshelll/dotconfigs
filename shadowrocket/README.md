# ShadowRocket

> submodules for shadowrocket

## Install

> copy the link from the submodule you want to install, and paste it in shadowrocket's "Import from URL" on module page.

- [Bilibili](https://raw.githubusercontent.com/sshelll/dotconfigs/master/shadowrocket/modules/bilibili.module)
- [ChatGPT](https://raw.githubusercontent.com/sshelll/dotconfigs/master/shadowrocket/modules/chatgpt.module)
- [Claude](https://raw.githubusercontent.com/sshelll/dotconfigs/master/shadowrocket/modules/claude.module)
- [Siri](https://raw.githubusercontent.com/sshelll/dotconfigs/master/shadowrocket/modules/siri.module)
- [Steam](https://raw.githubusercontent.com/sshelll/dotconfigs/master/shadowrocket/modules/steam.module)
